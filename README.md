# 📚 Manga & Anime Watchlist

![Manga & Anime](https://img.shields.io/badge/Manga%20%26%20Anime-Watchlist-blue?style=for-the-badge)

A beautifully designed web application to organize and track your *manga, anime, manhua, and manhwa collection* with advanced features like theme customization, achievements, and social sharing.

## Visit-the Website
- 🌐 https://anime-list-manager.vercel.app/

## 🌟 Features

### 📱 Mobile-First Design
- Fully responsive layout that works perfectly on all devices  
- Touch-friendly interface optimized for mobile use  
- Adaptive grid system for optimal viewing experience  

### 🎨 Dual Theme Modes
- *Light Mode*: Clean, bright interface for daytime use  
- *Prussian Mode*: Dark blue theme for comfortable nighttime browsing  
- Automatic theme preference saving  

### 📚 Collection Management
- Add, edit, and delete manga/anime entries  
- Track status (Watching/Reading, Completed, Watch Later)  
- Organize with intuitive filtering system  
- Quick search functionality  

### 🔍 Media Discovery
- Integrated with *Jikan API (MyAnimeList)*  
- Search for detailed anime and manga information  
- View ratings, synopsis, and recommendations  
- Directly add searched items to your list  

### 🏆 Achievement System
- Unlock achievements as you use the app  
- Track your progress with fun milestones  
- Visual indicators for earned achievements  

### 📤 Social Sharing
- Generate shareable links to your collection  
- Direct sharing to *Twitter* and *WhatsApp*  
- Import shared lists from other users  

### ❓ Comprehensive FAQ
- Easy-to-access help section  
- Expandable question-answer format  
- Covers all major features and usage

## 📋 How to Use

### Adding Items
1. Fill in the title of the manga/anime  
2. Add the source link (website URL)  
3. Select the current status  
4. Click *"Add to List"*

### Managing Your Collection
- *Edit*: Click the edit button on any item card  
- *Delete*: Remove items with the delete button  
- *Filter*: Use the filter buttons to view specific categories  
- *Search*: Use the quick search or detailed search modal  

### Using Themes
- Click the theme toggle button in the header  
- Switch between *Light* and *Prussian* modes  
- Your preference is automatically saved  

### Sharing Your List
1. Click the *"Share My List"* button  
2. Copy the generated URL or share directly to social media  
3. Others can import your list with one click

## 🌐 API Reference
This application uses the *Jikan API (Unofficial MyAnimeList API)* to fetch anime and manga data. The API is used for:
- Searching media details  
- Fetching recommendations  
- Displaying ratings and synopsis  

---

## 🔧 Customization

### Adding Custom Themes
Extend the theme system by adding new CSS variables in the :root selector and corresponding theme definitions.

### Modifying Achievements
Edit the achievementDefinitions array in the JavaScript to add new achievements or modify existing ones.
